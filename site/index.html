HOW A WISH
BECOMES A WORLD.

这个仓库同时是作品集和制作流程。每一个项目都是一个可独立构建的文件夹；根目录的脚本把它们组装成一个可导航的站点，GitHub Actions 再把站点发布到 Pages。

  1. 01

    CLONE

    git clone

    把整个许愿池下载到本地。所有项目、数据、字体与构建脚本都在里面，不依赖外部服务。

    git clone https://github.com/MY-Final/wishcraft
cd wishcraft

  2. 02

    MAKE A WISH

    projects/<your-wish>/

    在 projects/ 下新建一个目录，放入任何可构建的网页工程：Vite、React、Three.js，或者一个单文件 HTML。

  3. 03

    DECLARE IT

    wish.json

    写一个 wish.json，告诉构建脚本标题、年份、封面、构建命令和产物位置。作品集会读取它。

    {
  "id": "my-wish",
  "title": "MY WISH",
  "titleZh": "我的愿望",
  "year": "2026",
  "kind": "INTERACTIVE",
  "status": "WIP",
  "preview": "projects/my-wish/",
  "cover": "assets/covers/my-wish.jpg",
  "build": {
    "manager": "pnpm",
    "command": "pnpm build",
    "output": "dist"
  }
}

  4. 04

    PUSH

    main → Pages

    推送到 main。Actions 会依次构建每个项目、生成作品集并发布。刷新导航，新的世界就已经在里面。

    git add .
git commit -m "wish: my-wish"
git push

构建脚本：scripts/build-site.mjs · 部署：.github/workflows/pages.yml · 本地预览：node scripts/build-site.mjs --skip-install && node scripts/serve-site.mjs
