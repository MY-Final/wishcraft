# GARGANTUA — ambient soundtrack

`gargantua-ambient.ogg` is the optional deep-space ambient bed used by the
piece (the `M` shortcut / MUSIC button). It is a **procedurally synthesised
work**, generated from first principles by
[`tools/make-audio.py`](../../tools/make-audio.py). No third-party samples,
loops, presets, recordings or AI-generated audio are used.

## The track

| Property | Value |
| --- | --- |
| File | `gargantua-ambient.ogg` (Ogg Vorbis, stereo) |
| Duration | 40.000 s, seamless loop |
| Sample rate | 32 kHz |
| Size | ~0.45 MiB (466 KiB) |
| Peak / RMS | −3.0 dBFS / −15.4 dBFS |
| Character | sub drone (~36–55 Hz), slowly beating harmonic pad (43.2 Hz series), filtered solar-wind noise, high shimmer, 40 s swells; no melody, no vocals |

### Why it loops without a click

Every oscillator, beating pair and slow LFO completes an integer number of
cycles in exactly 40 s, and the noise layers are synthesised directly in the
frequency domain (hence periodic). The waveform is therefore sample-accurate
periodic: playing the file with `loop = true` has no crossfade, no gap and no
seam — including the sub drone, which is inaudible but would otherwise thump.

## Regenerating

Requires Python 3 with numpy. Ogg Vorbis encoding uses
[python-soundfile](https://python-soundfile.readthedocs.io/) (libsndfile
1.1+); when that is unavailable the script writes a small mono 16-bit WAV
fallback instead (~2.44 MiB at 40 s) and prints a reminder to update
`DEFAULT_SRC` in `src/audio.js`.

```bash
python tools/make-audio.py              # -> assets/audio/gargantua-ambient.ogg
python tools/make-audio.py --wav        # force the mono WAV fallback
python tools/make-audio.py --out-dir /tmp/audio-test
```

The generator is deterministic: `SEED = 20261102`, `DURATION = 40 s`,
`SAMPLE_RATE = 32 kHz` are fixed at the top of the script, so rerunning it
reproduces the same bed (encoder bitstreams may differ between libsndfile
versions; the audio content does not).

### Encoding note

The ffmpeg binary bundled with the browser tooling is a video-only build
(`--disable-everything`, no audio encoders), so Ogg Vorbis is encoded with
libsndfile through python-soundfile instead. No network access or third-party
audio is involved.
