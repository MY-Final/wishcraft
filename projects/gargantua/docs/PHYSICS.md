# GARGANTUA — 物理说明 / Physics Notes

> 这份文档解释画面里的每个结构由哪条方程决定，以及哪些部分是物理、哪些部分是艺术取舍。

---

## 1. 模型与单位

采用 **Schwarzschild 度规**（不转动、无电荷黑洞）：

```
ds² = -(1 - r_s/r) dt² + (1 - r_s/r)^-1 dr² + r² (dθ² + sin²θ dφ²)
```

代码单位取 **r_s = 2M = 1**（事件视界半径 = 1）：

| 量 | 值 |
| --- | --- |
| 质量 M | 0.5 |
| 事件视界 r_s | 1.0 |
| 光子球 | 1.5 r_s（3M） |
| ISCO（最内稳定圆轨道） | 3.0 r_s（6M） |
| 临界碰撞参数 b_c | 3√3 M ≈ 2.598 r_s |
| 相机距离 | 约 3–140 r_s |

所有天体距离、盘半径、相机半径都用 r_s 表示；HUD 中标注 `rₛ`。

## 2. 零测地线积分

光子沿零测地线运动。在轨道平面内令 `u = 1/r`，由守恒量 E、L 可得 Binet 方程：

```
d²u/dφ² + u = 3 M u²        (r_s = 2M = 1 时为 u'' = -u + 1.5 u²)
```

这条方程同时决定了阴影边缘、光子环、透镜倍率和多重像。片元着色器对每个像素执行一次 **RK4** 积分，而不是对屏幕做后处理扭曲。

### 初值

对每个像素，从相机位置 `ro` 和像素视线 `rd` 出发：

- `e1 = ro / |ro|`，`e2 = normalize(rd - (rd·e1)e1)`；
- 局部静止观者测得的径向/切向分量 `dr = rd·e1`、`dt = |rd - dr e1|`；
- `u0 = 1/r0`；
- `du/dφ|₀ = -u0 · √(1 - r_s/r0) · dr / dt`（局部正交标架修正）；
- 碰撞参数 `b = r0 · dt / √(1 - r_s/r0)`；光子角动量沿盘轴的投影 `b_z` 用 `ro × rd` 计算（含 √f 修正与反向追踪的符号）。

### 步进与终止

- 角步长随质量档位变化（Standard 0.085 / High 0.052 / Cinematic 0.038 rad），最多 150 / 280 / 420 步；
- 轨道平面角用旋转递推（`cosΔφ`, `sinΔφ` 常数）推进，热循环内没有三角函数；
- `u ≥ 1`（r ≤ r_s）→ 判定被视界吸收，阴影为纯黑；
- `u ≤ 0`（r → ∞）→ 用 `u = 0` 处插值出逃逸方向，采样程序化天空；
- 步数耗尽 → 视为近临界光线被吸收。这一截断只影响临界曲线附近的极窄环，另以 `photonRingBoost` 对临界环做受限增益（见 §7）。

### 为什么阴影半径是 b_c

由有效势 `V_eff = u² - u³` 可推出不稳定圆轨道（光子球）位于 `u = 2/3`，对应 `b_c = 3√3 M`。`b < b_c` 的光线落入视界，`b > b_c` 的光线逃逸——这就是阴影边界。脚本 `tools/physics-check.mjs` 用独立 JS 积分复核：二分测得 2.598076 r_s，误差 4.4×10⁻¹⁵。

## 3. 吸积盘

盘位于赤道面 `y = 0`（世界坐标 +Y 为盘轴），是**几何薄盘**。

### 3.1 穿越检测

沿测地线逐步检查三维位置 `p(φ) = r(φ)(cosφ e1 + sinφ e2)` 的 y 分量变号；变号时在段内线性插值得到穿越点。同一条光线可以多次穿越盘面——这产生次级像、盘背面像与光子环上的多次穿越。每条光线最多累积其步数预算内的全部穿越。

### 3.2 温度

采用 Shakura–Sunyaev 型温度分布，锚定内边缘：

```
T(r) = T_peak · (r_in / r)^(3/4)
```

默认 `T_peak = 5800 K`、`r_in = 3 r_s`。高温内缘接近白热，外缘降到 ~2000 K 的深橙红。UI 里可以直接调 `Peak temperature` / `Inner radius` / `Outer radius`。

### 3.3 Doppler 增亮与引力红移

对圆轨道 Keplerian 发射体，观测/发射频率比为

```
g = √(1 - 3M/r) / (1 - Ω b_z),      Ω = √(M/r³)
```

其中 `b_z` 是光子角动量沿盘轴的分量（由相机处的 `ro × rd` 守恒给出，符号按实际光子动量修正）。`g > 1` 为蓝移/增亮，`g < 1` 为红移/变暗：

- 颜色：`T_obs = T · mix(1, g, redshift)`；
- 亮度：`pow(g, 4 · beaming)`（`g⁴` 是 bolometric beaming，可用 `beaming` 参数线性减弱）；
- 观测频率偏移即 `g`。默认参数下，ISCO 处接近侧 `g ≈ 1.05`，远离侧 `g ≈ 0.53`，产生明显的左右亮度不对称。

### 3.4 湍流与差速旋转

盘面图案由多层程序化 fBm 构成，采样在（旋转角, log r）空间，角向坐标用 `(cos a, sin a)` 避免接缝；两层不同角速度的图案叠加形成剪切，角速度按 `Ω(r) = √(M/r³)` 随半径变化。`Orbital speed` 控制演化速度，`Turbulence` 控制图案对比度。视觉目标是“流动的气体”，不是 GRMHD 模拟；这一点在 README 中明确标注。

### 3.5 发射-吸收合成

每个穿越点计算光学深度

```
τ = opacity · density · clumping(thickness) / max(|dir·ŷ|, 0.028)
α = 1 - exp(-τ)
```

按从相机到远处的顺序做前向合成（front-to-back）：

```
color += transmittance · emission · (0.35 + 0.65 α)
transmittance *= (1 - α)
```

这样近侧盘面会遮挡其后更高阶的像，同时保留薄盘边缘的半透明辉光。

## 4. 程序化天空

星空与银河全部由方向 `dir` 上的哈希/噪声生成，**没有任何全景贴图**：

- 星点位于（方位角、仰角）网格单元内，PSF 半径钳制到至少约 1 像素，避免亚像素混叠；多层不同密度/亮度/色温；
- 银河带由银道面法向的高斯带 + 域扭曲 fBm 云气 + 尘埃带构成，核心方向有暖色增亮；
- 天空同样经过测地线积分：逃逸方向越靠近临界曲线，背景被拉伸/放大越强，形成自然的爱因斯坦环与多重像。

## 5. 后处理

`src/post.js` 是手写的 HDR 管线（没有 EffectComposer / UnrealBloom）：

1. 半分辨率亮度阈值前处理（soft knee）；
2. 13-tap 降采样 mip 链（4–6 级，随质量档）；
3. tent 滤波加性升采样合成 bloom；
4. 合成：`HDR + bloom·strength` → exposure → 逐通道 ACES fitted → 径向色散（RGB 分通道径向偏移）→ 暗角 → 胶片颗粒（按亮度加权，保持阴影纯净）→ gamma → dither。

调试视图 `1` 走“曝光 + ACES 原始 HDR”，`9` 显示 bloom 高光源，其余调试视图绕过色调映射。

## 7. 数值边界与艺术取舍（诚实声明）

- **非转动黑洞**：这是 Schwarzschild，不是 Kerr。没有参考系拖曳、没有自旋致阴影变形。
- **薄盘 + 发射-吸收**：没有体渲染、没有散射、没有磁流体动力学；湍流是程序化、艺术可控的图案。
- **有限步长**：近临界光线会绕光子球多圈，步数预算把更高阶像截断在临界环附近；`photonRingBoost` 只对 `|b - b_c|` 内极窄环加一个受限亮度增益，避免伪造盘面结构。
- **静态观者**：相机按局部静止观者处理；没有模拟相机自身的运动像差。
- **天空是艺术资产**：星点分布、色温、银河形态均为程序化创作，不宣称对应真实星表。
- **不伪造**：核心结构（阴影、光子环、多次穿越、透镜、Doppler、红移）都来自逐像素测地线积分；没有黑球、平面圆环、贴图或视频。
